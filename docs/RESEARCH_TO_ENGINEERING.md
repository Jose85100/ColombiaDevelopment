# Research → Engineering

## Estados
R0 Idea → R1 Formulación → R2 Diseño → R3 Prototipo → R4 Validación → R5 Piloto.

## Gate mínimo por proyecto
- Problema y usuario/decisor.
- Hipótesis falsable.
- Documento fuente de Drive.
- Fuentes de datos y licencias.
- Diagrama de contexto y componentes.
- Baseline y métricas.
- Código reproducible y tests.
- Riesgos: privacidad, seguridad, sesgo, regulación y uso indebido.
- Limitaciones y criterio explícito de no-producción.

## Trazabilidad
Drive conserva formulación, investigación, decisiones institucionales y publicación. GitHub conserva implementación, diagramas, contratos, experimentos, pruebas y resultados reproducibles.
